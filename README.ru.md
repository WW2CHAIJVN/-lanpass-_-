## Проблема

Компьютерный класс: десятки ПК, один коммутатор, одна подсеть. Но в «Сети» ничего не отображается.

Причин два уровня.

**Поверхностный**: домашняя группа появилась в Windows 7 и была **удалена в Windows 10 1803**. У Win7 и Win10/11 нет общего механизма.

**Корневая причина**: начиная с Windows 10 1709 параметр `AllowInsecureGuestAuth` по умолчанию равен 0. Win10/11 отклоняет любой анонимный доступ по SMB. Даже если обойти домашнюю группу и подключиться по IP, вы получите *«Политики безопасности вашей организации блокируют неаутентифицированный гостевой доступ»*.

**Исправление одной только домашней группы не помогает. Блокирует аутентификация SMB.**

## Возможности

| | |
|---|---|
| **Без зависимостей** | Только встроенные `mshta` / `cmd` / `net` / `ping` / `arp`. Без .NET, VC++, Java, Python, Node |
| **Без служб обнаружения** | Работает, даже если домашняя группа, обнаружение сети, Computer Browser, SSDP и DNS отключены |
| **Между версиями** | Win7 / Win10 / Win11 в обе стороны |
| **Две роли** | Клиент учителя для всего класса, клиент ученика для сдачи в один клик |
| **Автоисправление** | Записывает 4 значения реестра, снимающие блокировку гостевого доступа |
| **Активное обнаружение** | Таблица ARP + ping-сканирование подсети, без служб системы |
| **Память устройств** | Кэш списка устройств, мгновенный запуск |
| **Низкая нагрузка** | 34 МБ ОЗУ, 0% CPU в простое, без опроса |

## Быстрый старт

1. Скопируйте папку на каждый ПК
2. ПК учителя: запустите `教师端.exe`; ПК ученика: `学生端.exe`
3. Нажмите «配置共享» (настроить общий доступ), подтвердите UAC
4. Учитель: нажмите «刷新学生机» (обновить учеников). Пусто? Нажмите «全段扫描» (полное сканирование)
5. Нажмите «打开» (открыть) в строке ученика

Нет диска D:? Измените `D:\lan-share` на существующий путь в `setup-share.bat` и `app.hta`.

## Технические заметки

Обнаружение читает локальную таблицу ARP (уровень 2, не зависит от служб Windows). Если ARP пуста, выполняется ping-сканирование подсети (254 адреса, 32 параллельно, около 4 секунд) — ping нужен только для заполнения ARP, а не для ожидания ответа ICMP.

Интерфейс — HTA, отрисовываемый встроенным `mshta.exe` (режим совместимости IE8). Весь исходный код — обычный HTML + JScript, доступный для проверки.
